# SIEM/SOC Mini Lab

## Overview
A hands-on cybersecurity lab built to practise security monitoring, log analysis, and detection engineering using **Wazuh and Suricata** in a virtualized environment.

## Lab Environment
- **Wazuh:** SIEM and security event monitoring
- **Suricata:** Network threat detection and custom rules
- **Kali Linux:** Controlled reconnaissance and security testing
- **Ubuntu:** Monitored host running Wazuh

## Key Activities
- Configured Wazuh agent monitoring.
- Simulated SSH failed logins and repeated authentication attempts.
- Created custom Suricata rules to detect TCP SYN probes.
- Built Wazuh detection rules and tested alert correlation.
- Captured screenshots and documented results.

## Repository Structure
- `Report/` – Final project report
- `Screenshots/` – Evidence from lab activities
- `Diagram/` – Lab architecture diagram
- `Rules/` – Custom Suricata and Wazuh rules

## Disclaimer
This lab was conducted in a controlled virtual environment for educational purposes. All testing was performed against lab systems.
